## После первого ревью

Исходные результаты приложены распакованной папкой `allure-results/` в корне проекта.
Методы API-клиента, Page Object и методы, описывающие шаги теста, используют `@Step`.
В Maven подключён AspectJ для исполнения аннотаций. Параметры шагов не сохраняются
в публикуемых результатах, чтобы исключить пароли и токены.

Пользователь из `LoginTest.createUserViaApi()` удаляется в унаследованном
`UiTestBase.tearDown()` с аннотацией `@After`: вызов `user.close()` находится
в `finally` и выполняется даже при ошибке скриншота или закрытия браузера.
`TestUser.close()` проверяет успешное удаление (202), а затем отказ входа (401).
Эти действия видны в Allure в шаге «Удалить тестового пользователя и проверить невозможность входа».

Для отчёта из приложенной папки выполните:

```sh
mvn allure:serve -Dallure.results.directory=allure-results
```
