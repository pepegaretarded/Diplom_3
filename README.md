# Diplom_3

UI-тесты Stellar Burgers. Java 11, Maven, JUnit 4, Selenium WebDriver,
REST Assured и Allure. Ветка `develop3`.

## Сценарии

Каждый сценарий запускается отдельно в Google Chrome и Яндекс Браузере:

- Успешная регистрация с паролем из 6 символов.
- Ошибка регистрации с паролем из 5 символов.
- Вход с главной страницы.
- Вход через личный кабинет.
- Вход через форму регистрации.
- Вход через форму восстановления пароля.
- Переход к булкам из раздела соусов.
- Переход к соусам.
- Переход к начинкам.

Итого 18 тестов. Page Object-классы лежат в пакете `pages`,
тестовые классы разделены на регистрацию, вход и конструктор.
У каждой страницы отдельный класс. В тестах нет локаторов.
Вместо фиксированных задержек используются явные ожидания.
Каждый тест получает отдельный браузерный профиль и закрывает браузер.
Пользователи для входа создаются через API и удаляются в `@After`.
В тесте регистрации пользователь создаётся через UI и также удаляется через API.

## Быстрый запуск на этом Mac

В терминале IntelliJ IDEA, открытом в папке проекта:

```sh
./run-tests.sh
```

На macOS скрипт выбирает установленную Java 11 для Apple Silicon,
а при её отсутствии — доступную Java 11,
запускает проверки и формирует Allure-отчёт. На этом Mac Java 11
для Apple Silicon зарегистрирована и выбирается автоматически.

## Подготовка

Установите JDK 11, Maven, Chrome и Яндекс Браузер.
ChromeDriver должен соответствовать версии Chrome; Selenium Manager может
подобрать его автоматически. Для Яндекс Браузера скачайте подходящий
[YandexDriver](https://github.com/yandex/YandexDriver/releases).
Ветка версии драйвера должна совпадать с версией Яндекс Браузера.

На этом Mac драйверы подготовлены в `~/.cache/diplom-drivers/`.
Путь к Яндекс Браузеру по умолчанию:
`/Applications/Yandex.app/Contents/MacOS/Yandex`.

## Запуск из IntelliJ IDEA

Откройте `pom.xml` как Maven-проект, выберите JDK 11.
В панели Maven нажмите Execute Maven Goal:

```sh
mvn clean test allure:report -Dchrome.driver=/Users/mac/.cache/diplom-drivers/chromedriver
```

На другом компьютере укажите собственные пути или позвольте Selenium Manager
подобрать ChromeDriver. Дополнительные параметры:

- `-Dbrowsers=chrome` или `-Dbrowsers=yandex`: один браузер, по умолчанию оба.
- `-Dchrome.binary=/путь/к/Chrome`: другой исполняемый файл Chrome.
- `-Dchrome.driver=/путь/chromedriver`: явный путь к ChromeDriver.
- `-Dyandex.driver=/путь/yandexdriver`: путь к YandexDriver.
- `-Dyandex.binary=/путь/к/браузеру`: путь к исполняемому файлу Яндекс Браузера.
- `-Dheadless=true`: запуск без видимых окон.
- `-Dbase.url=https://адрес-стенда`: другой адрес приложения.
- `-Dwebdriver.log=true`: диагностические логи драйвера в `target/`.

Команды работают и из терминала в папке проекта.

## Отчёт

`target/allure-results` содержит результаты со скриншотами финального состояния.
`target/site/allure-maven-plugin/index.html` — HTML-отчёт.
Для просмотра используйте `mvn allure:serve` после прогона.
Сохранённый отчёт для ревью: `reports/allure-report.zip`.
После изменения тестов обновите сохранённый архив отчёта.
