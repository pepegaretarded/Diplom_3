# Diplom_3

Автотесты UI Stellar Burgers. Дипломный проект Яндекс Практикума.

## Подготовка

- JDK 11.
- Maven 3.9.x.
- Рабочая ветка: `develop3`.

Откройте `pom.xml` как Maven-проект в IntelliJ IDEA и выберите JDK 11.

Проверка сборки:

```sh
mvn clean test
```

Сейчас подготовлен каркас проекта; тесты и специальные зависимости ещё не добавлены.
Настройка запуска в Google Chrome и Яндекс Браузере будет добавлена вместе с UI-тестами.
